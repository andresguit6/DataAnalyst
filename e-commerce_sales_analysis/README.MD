# 🛒 E-commerce Sales Analysis Dashboard

## 📌 Descripción del Proyecto
Este proyecto analiza el rendimiento de ventas de un negocio de e-commerce utilizando Power BI.  

El dashboard permite identificar tendencias de ventas, rentabilidad, desempeño por regiones y categorías de productos.

### 📊 El análisis proporciona insights sobre:
- 📈 Tendencias de ventas a lo largo del tiempo
- 🌍 Rentabilidad por región
- 🛍️ Categorías de productos más vendidas
- 📌 Indicadores clave del negocio
- 💰 Relación entre ventas y ganancias

## 🛠️ Herramientas Utilizadas
- 📊 Power BI
- 📑 Excel
- 🧹 Limpieza de datos
- 📉 Visualización de datos
- 📋 Análisis de negocio
